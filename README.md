# Fyndra

> **Prouvez vos compétences IT, trouvez votre mission**

La plateforme cloud éducative nouvelle génération qui transforme les compétences IT en opportunités professionnelles.

## 🎯 Vision

Fyndra révolutionne le recrutement tech en connectant formation, évaluation pratique et emploi. Plus de CV bidons - place aux preuves concrètes de compétences.

## ✨ Fonctionnalités

### 🟦 Pour les candidats / apprenants
- 🎮 **Système de cartes de compétence** - Progressez de manière ludique
- 🧠 **Questionnaires techniques intelligents** - Évaluations adaptatives
- 💻 **VM éphémères scénarisées** - Tests en environnement réel
- 📄 **Rapports détaillés** - Score, points forts, axes d'amélioration
- 📌 **Suivi de progression** - Historique complet de vos parcours

### 🟨 Pour les formateurs / centres de formation
- 🧰 **Bibliothèque de scénarios** - Contenus pratiques prêts à l'emploi
- 🧑‍🏫 **Suivi individuel** - Monitoring des apprenants en temps réel
- 📁 **Preuves pédagogiques** - Génération automatique de rapports
- 🔐 **Environnements sécurisés** - Zero Trust by design

### 🟩 Pour les recruteurs / entreprises
- ✅ **Profils pré-qualifiés** - Candidats testés en conditions réelles
- 🧪 **Scénarios sur-mesure** - Créez vos propres tests de recrutement
- 📬 **Candidatures enrichies** - Rapports techniques inclus
- 🎯 **Matching intelligent** - Algorithme de correspondance compétences/offres

## 🚀 Technologies

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **State Management**: Zustand
- **Routing**: React Router DOM
- **Build Tool**: Vite
- **Package Manager**: pnpm

## 🛠️ Installation

### Prérequis
- Node.js 18+
- pnpm

### Démarrage rapide

```bash
# Cloner le repository
git clone https://github.com/PypNetty/fyndra.git
cd fyndra

# Installer les dépendances
pnpm install

# Lancer en mode développement
pnpm dev

# Build pour la production
pnpm build
```
